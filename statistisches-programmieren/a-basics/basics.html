3.2 Selecting elements: subsetting - “[ ]”

Use subsetting via [ ] to access elements of vectors. Two methods: + Subsetting via indices (3.2.1) + Subsetting via boolean values (3.2.2)

3.2.1 Subsetting via indices - “-”

# Subsetting via indices
stack
[1] 4 7 6 2 3 5
# top card
stack[1]
[1] 4
# second and fourth card
stack[c(2, 4)]
[1] 7 2
# first and last card
stack[c(1, length(stack))] # use length() for flexibility of code
[1] 4 5
# subsetting created a new vector
stack[3:5] # gets new indices
[1] 6 2 3
# assinging elements to temp
temp <- stack[3:5]
temp # "temporary"
[1] 6 2 3
# accessing first card in temp:
temp[1]
[1] 6
stack[3:5][1] # nested alternative
[1] 6
# alternatively: caching indices
ind <- 3:5
stack[ind]
[1] 6 2 3

What happenns if we try to access non-existing elements?

# Accessing non-existing elements
stack[c(2, 9, 2)] # NA (Not Available) appear
[1]  7 NA  7

Omitting specific elements:

# Omitting specific elements via "-"
# selecting all elements except specified ones
stack[-c(3:5)]
[1] 4 7 5
stack[-c(3:5, 1)]
[1] 7 5

Dealing the cards equally:

# Player 2 receives every second card
ind <- c(1, 3, 5)

hand1 <- stack[ind]
hand1
[1] 4 6 3
hand2 <- stack[-ind]
hand2
[1] 7 2 5

3.3 presents approach that is appliable to all lengths of vectors.

3.2.2 Subsetting with Boolean Values

# Subsetting with boolean values
stack
[1] 4 7 6 2 3 5
# select alternating
bool1 <- c(TRUE, FALSE, TRUE, FALSE, TRUE, FALSE)
bool1
[1]  TRUE FALSE  TRUE FALSE  TRUE FALSE
hand1 <- stack[bool1]
hand1
[1] 4 6 3
# Can reverse operation for second player via negation
hand2 <- stack[!bool1]
hand2
[1] 7 2 5

3.3 Recycling

# Selecting cards alternatung via recycling
stack
[1] 4 7 6 2 3 5
# subsetting vec recycled till reaching length of stack
stack[c(TRUE, FALSE)] # 6 divisible by 2, thus "complete recycling"
[1] 4 6 3
# incomplete recycling - subsetting vector cuts off stack
stack[c(TRUE, FALSE, FALSE, FALSE)] #  4 no divisor of 6
[1] 4 3
# "4" 7 6 2 "3" 5

Recycling also common in arithmetic operations:

# Recycling in arithmetic operations
y <- 1:5 * c(-1, 1)
Warning in 1:5 * c(-1, 1): longer object length is not a multiple of shorter
object length
y
[1] -1  2 -3  4 -5

3.5 Calculating with Boolean Values

3.5.1 Absolute and Relative Frequencies – sum(), mean()

# Ex: how many cards with at least val 5
# cards p1
hand1 >= 5
[1] FALSE  TRUE FALSE
sum(hand1 >= 5)
[1] 1
# cards p2
hand2 >= 5
[1]  TRUE FALSE  TRUE
sum(hand2 >= 5)
[1] 2
Important

R encodes TRUE as 1 and FALSE as 0 - thus, can use sum() to compute the number of TRUE.

This also applies to other arithemtic operations:

# 1 + 0 + 1
TRUE + FALSE + TRUE
[1] 2
# T + F + T; alternatively

# 2 * 1 + 1 * 0
2 * TRUE + 1 * FALSE
[1] 2
# Proportion of TRUE values - use mean()
mean(stack >= 5) # 50% of cards greater or equal to 5
[1] 0.5
# Ex: Did p1 receive more cards greater than or equal to 5 than p2?
sum(hand1 >= 5) > sum(hand2 >= 5) # FALSE
[1] FALSE

3.5.2 Determining Index Values - which()

Used when interested in specific indices fulfilling some conditions. So far:

(1:length(vec))[bool] # reveals at what index TRUE lies
stack
[1] 4 7 6 2 3 5
# retrieve indices
1:length(stack)
[1] 1 2 3 4 5 6
stack == 7 
[1] FALSE  TRUE FALSE FALSE FALSE FALSE
index <- (1:length(stack))[stack == 7]
index # 7 is at position 2
[1] 2
# alternatively, and more conveniently
which(stack == 7)
[1] 2
# Ex: positions with cards equal or greater than 5
which(stack >= 5)
[1] 2 3 6
# Ex: position of first card with val 5 or greater
ind1 <- which(stack >= 5)[1]
ind1
[1] 2
stack[ind1] # value of this card
[1] 7

What happens when calling which() on non-existing indices:

# no element < 0 results in empty vec
which(stack < 0)
integer(0)
length(which(stack < 0))
[1] 0
length(which(stack < 0)) == 0
[1] TRUE
# trying to access non-ex elements
which(stack < 0)[1] # NA
[1] NA
stack[which(stack < 0)[1]] # NA
[1] NA

3.6 Replacing and Swapping Values

Elements of a vector can be replaced by selecting positions and assigning new values:

vector[position] <- replacement

x <- c(2, -5, 3, 4, -1)

# double all positive values
x[x > 0] <- x[x > 0] * 2
x
[1]  4 -5  6  8 -1
# replace all negative values by 0
x[x < 0] <- 0
x
[1] 4 0 6 8 0
Important

When assigning a single value to multiple positions, recycling takes place.

For example, 0 is recycled to the length of x[x < 0].

3.6.1 Swapping Values

stack <- c(4, 7, 6, 2, 3, 5)

# swap first and last card - wrong!
stack_new <- stack
stack_new[1] <- stack_new[length(stack_new)]
stack_new[length(stack_new)] <- stack_new[1]
stack_new
[1] 5 7 6 2 3 5

The first value is overwritten before it can be assigned to the last position.

We can instead access the values of the original stack:

stack_new <- stack

stack_new[1] <- stack[length(stack)]
stack_new[length(stack_new)] <- stack[1]

stack_new
[1] 5 7 6 2 3 4

Alternatively, use a temporary object:

stack_new <- stack

temp <- stack_new[1]
stack_new[1] <- stack_new[length(stack_new)]
stack_new[length(stack_new)] <- temp

stack_new
[1] 5 7 6 2 3 4
Important

When values are overwritten sequentially, store values that are still needed in a temporary object.

3.7 Good Programming Practice

3.7.1 Meaningful Object Names and Special Characters

Object names should be short and meaningful.

Examples of meaningful names:

stack
mixed_stack
hand_player1

Avoid names such as:

x
1.hand
hand 1
kartenstoß
blätter1
s

General rules:

  • use short and descriptive names
  • object names cannot start with a number
  • avoid spaces and special characters
  • avoid umlauts (ä, ö, ü) and ß
  • use nouns for objects
  • prefer lowercase names
  • . and _ can be used to separate words
Note

R is case-sensitive. Thus, stack and Stack refer to different objects.

3.7.2 General and Automated Programming

Code should be written such that it still works when the underlying data changes.

stack <- c(4, 7, 6, 2, 3, 5)

# last card - expandable
stack[6]
[1] 5
# last card - general
stack[length(stack)]
[1] 5
# every second card - expandable
stack[c(1, 3, 5)]
[1] 4 6 3
# every second card - general
stack[c(TRUE, FALSE)]
[1] 4 6 3

If the stack is extended:

stack <- c(stack, 9, 8)
stack
[1] 4 7 6 2 3 5 9 8

the manually specified code no longer works correctly:

stack[6]
[1] 5
stack[c(1, 3, 5)]
[1] 4 6 3

while the general code automatically adapts:

stack[length(stack)]
[1] 8
stack[c(TRUE, FALSE)]
[1] 4 6 3 9
Important

Program as generally and automatically as possible. Let R determine information such as vector lengths or positions instead of hard-coding them.

3.8 Exercises

Ex 1: Counting Boolean Values

stack <- c(4, 7, 6, 2, 3, 5)

# number of cards with value >= 4
sum(stack >= 4)
[1] 4
# alternatively
length(stack[stack >= 4])
[1] 4
# using which()
length(which(stack >= 4))
[1] 4

sum(stack >= 4) works because R encodes TRUE as 1 and FALSE as 0.

Using which() is unnecessary when we only want to select or count elements based on a condition.

Ex 2: Vector Operations

x <- (1:6) * c(-1, 1)
x
[1] -1  2 -3  4 -5  6

c(-1, 1) is recycled:

1:6       1  2  3  4  5  6
c(-1, 1) -1  1 -1  1 -1  1
           ↓  ↓  ↓  ↓  ↓  ↓
x         -1  2 -3  4 -5  6

Replace all non-positive values by their negative value:

x[x <= 0] <- -x[x <= 0]
x
[1] 1 2 3 4 5 6

Multiply using recycled Boolean values:

x <- x * c(TRUE, FALSE)
x
[1] 1 0 3 0 5 0

Since TRUE = 1 and FALSE = 0, every second value becomes 0.

Select values different from 0 and smaller than 5:

x <- x[x != 0 & x < 5]
x
[1] 1 3

Select elements using numerical indices:

x <- x[c(0:3, length(x), 2, 1)]
x
[1]  1  3 NA  3  3  1
Note

When indexing, 0 is ignored. Repeated indices select the corresponding element multiple times.

Ex 3: Select All Elements Except the Last \(k\)

x <- 1:5
x
[1] 1 2 3 4 5

Approach 1:

# brackets needed due to operator precedence
x[1:(length(x) - 2)]
[1] 1 2 3

Approach 2:

# exclude last two positions
x[-c(length(x) - 1, length(x))]
[1] 1 2 3

Generalizing to the last k elements:

k <- 2

# approach 1
x[1:(length(x) - k)]
[1] 1 2 3
# approach 2
x[-((length(x) - k + 1):length(x))]
[1] 1 2 3
Function
omit_last_elmt <- function(vec, k) {
  if (length(vec) >= k + 1) {
    vec[1:(length(vec) - k)]
  } else NA
}

omit_last_elmt(x, 2)
[1] 1 2 3

Alternatively, using seq_len():

omit_last_elmt <- function(vec, k) {
  if (length(vec) >= k + 1) {
    vec[seq_len(length(vec) - k)]
  } else NA
}

omit_last_elmt(x, 2)
[1] 1 2 3

Ex 4: Logical Conditions

age <- c(16, 18, 19, 24, 28, 32, 32, 45)

# number of entries
length(age)
[1] 8
# percentage between 18 and 27
mean(age >= 18 & age <= 27) * 100
[1] 37.5
# younger than 20 or older than 30
sum(age < 20 | age > 30)
[1] 6

Ex 5: Swapping Cards Between Two Players

hand1 <- c(4, 6, 3)
hand2 <- c(7, 2, 5)

This approach does not work:

hand1[1] <- hand2[1]
hand2[1] <- hand1[1]

hand1[1] is overwritten before its original value can be assigned to hand2[1].

Use a temporary object instead:

hand1 <- c(4, 6, 3)
hand2 <- c(7, 2, 5)

temp <- hand1[1]

hand1[1] <- hand2[1]
hand2[1] <- temp

hand1
[1] 7 6 3
hand2
[1] 4 2 5
