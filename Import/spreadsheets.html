R for Data Science (2e), Chapter 20

Excel

Data organized in worksheets inside spreadsheet files.

Prerequisites

library(readxl)
library(tidyverse)
library(writexl)

Getting started

  • read_xls() - reads Excel files with xls format

  • read_xlsx() - reads Excel files with xlsx format

  • read_excel() - reads both xls and xlsx - guesses file type based in input

Data types

CSV: Values are strings - everything is a string.

Excel: Values (Cells) can be four things: + boolean - TRUE, FALSE, NA + number - “10”, “10.5”, etc. + datetime - “11/1/21”, “11/1/21 3:00 PM”, etc. + text string - “ten”, etc.

Recommendation: Let readxl guess the column types - confirm column types - if necessary, go back and re-import specifying col_types. If column has mix of types - set type of column to "list", which loads column as list of length 1, where type of each element of vector is guessed.
