Functions

R for Data Science (2e), Chapter 25

Introduction

Functions allow automation of common tasks.

Advantages:

  • Code is easier to understand with named functions.

  • Updating code in less places, if needed.

  • Eliminate chance of making mistakes when copy-and-pasting

  • Improved reusability

Rule of Thumb:

Whenever block of code is copied and pasted twice - consider writing a function.

Three useful types of functions:

  • Vector functions - Input: One or more vectors; Output: Vector

  • Data frame functions - Input: Data frame; Output: Data frame

  • Plot functions - Input: Data frame; Output: Plot

Writing a function

Analyze code - what parts are constant and what parts vary. Above code:

(a - min(a, na.rm = TRUE)) / (max(a, na.rm = TRUE) - min(a, na.rm = TRUE))
(b - min(b, na.rm = TRUE)) / (max(b, na.rm = TRUE) - min(b, na.rm = TRUE))
(c - min(c, na.rm = TRUE)) / (max(c, na.rm = TRUE) - min(c, na.rm = TRUE))
(d - min(d, na.rm = TRUE)) / (max(d, na.rm = TRUE) - min(d, na.rm = TRUE))

Replacing the parts with █:

(█ - min(█, na.rm = TRUE)) / (max(█, na.rm = TRUE) - min(█, na.rm = TRUE))

Need three things:

  1. Name - here we’ll use rescale01.
  2. Arguments - varying across calls, here jsut one - call it x.
  3. Body - code that’s repeated across all calls.

Template for creating function:

name <- function(arguments){
   body
}

Can write function as:

rescale01 <- function(x){
   (x - min(x, na.rm = TRUE)) / (max(x, na.rm = TRUE) - min(x, na.rm = TRUE))
}

clamp <- function(x, min, max){

}

clean_number <- function(x){
  
  is_pct <- str_detect(x, pattern = "%")
  
  num <- x |>
    str_remove_all(pattern = "%") |>
    str_remove_all(pattern = ",") |>
    str_remove_all(pattern = fixed("$")) |>
    as.numeric()
  
  if_else(is_pct, num / 100, num)
  
}

Indirection and tidy evaluation

grouped_mean() - computes the mean of mean_var grouped by group_var:

grouped_mean <- function(df, group_var, mean_var){
  
  df |>
    group_by(group_var) |>
    summarize(mean(mean_var))
  
}

What causes indirection?

Dplyr uses tidy evaluation allowing to refer to names of variables inside data frame without any special treatment.

Need wy to tell group_by() and summarize() not to treat group_var and mean_var as the name of the variables, but instead look inside them for the variable we actually want to use.

Solution of tidy evaluation is called embracing - i.e., wrapping var in braces { var } - tells dplyr to use variables stored inside the argument, not the argument as the literal variable name - makes dplyr look inside var rather than looking for variable called var.

df <- tibble(
  mean_var = 1,
  group_var = "g",
  group = 1,
  x = 10,
  y = 100
)

grouped_mean <- function(df, group_var, mean_var){
  df |>
    group_by({{ group_var }}) |>
    summarize({{ mean_var }})
}

df |> 
  grouped_mean(group, x)
# A tibble: 1 × 2
  group     x
  <dbl> <dbl>
1     1    10

When to embrace?

Key - figuring out which arguments to “embrace”

\(\rightarrow\) documentation.

Two most common sub-types of tidy evaluation:

  • Data-masking - used in arrange(), filter(), summarize() - compute with variables

  • Tidy-selection - used for select(), relocate(), rename()

E.g., see ?arrange(), the “…” argument.

Data- masking vs. tidy-selection

Important

Data-masking

Functions - group_by(), mutate(), filter(), summarise() \(\rightarrow\) Every argument is interpreted as an expression referring to a column.

E.g., group_by(year, month, day) - Find column called year, then month, then day.

Tidy-select

Functions - select(), across(), pick() \(\rightarrow\) Don’t evaluate expressions into vectors.

E.g., pick(c(year, month, day)) - select these three columns.

count_missing <- function(df, group_vars, x_var){
  df |>
  group_by({{ group_vars }}) |>
  summarize(
    n_miss = sum(is.na({{ x_var}})),
    .groups = "drop"
  )
}

 flights |>
   count_missing(c(year, month, day), dep_time)
# Issue
 df |> group_by(c(year, month, day)) # Error: arg must be size 1
# See ?group_by also

# Solution pick(), see ?pick() -> using select semantics while inside a "data-masking" function like mutate() or summarize().
count_missing <- function(df, group_vars, x_var){
  
  df |>
    group_by(pick({{ group_vars }})) |>
    summarize(
      n_miss = sum(is.na({{ x_var}})),
      .groups = "drop"
    )
  
}

flights |>
  count_missing(c(year, month, day), dep_time)

count_wide <- function(data, rows, cols) {

      values_from = n,
      names_sort = TRUE,
      values_fill = 0
    )
}

histogram <- function(df, var, binwidth = NULL){
  
  df |>
    ggplot(
      mapping = aes(x = {{ var }})
    ) +
    geom_histogram(binwidth = binwidth)
  
}

hex_plot <- function(df, x, y, z, bins = 20, fun = "mean") {
  df |> 
    ggplot(aes(x = {{ x }}, y = {{ y }}, z = {{ z }})) + 
    stat_summary_hex(
      aes(color = after_scale(fill)), # make border same color as fill
      bins = bins, 
      fun = fun,
    )
}

sorted_bars <- function(df, var){
  df |>
    mutate({{ var }} := fct_rev(fct_infreq({{ var }}))) |> # ':=' evaluate left-hand side first, then use the resulting name
    ggplot(aes(y = {{ var }})) +
    geom_bar()
}

Labeling

rlang::englue() - works similar to str_glue() - any value wrapped in { } will be inserted into the string - also understands { }, which automatically inserts appropriate variable name:

histogram <- function(df, var, binwidth){
  label <- rlang::englue("A histogram of {{var}} with binwidth {binwidth}")
  
  df |>
    ggplot(aes(x = {{ var }})) +
    geom_histogram(binwidth = binwidth) +
    labs(title = label)
}

diamonds |> histogram(carat, 0.1)
