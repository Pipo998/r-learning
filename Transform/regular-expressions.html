Note

Letters and number are called literal characters - they match exactly. Punctuation characters .,+, *, [, ], are metacharacters - have special meaning.

E.g., . will match any character - a. matches string containing “a” followed by any character:

str_view(c("a", "ab", "ae", "bd", "ea", "eab"), pattern = "a.")
[2] │ <ab>
[3] │ <ae>
[6] │ e<ab>

 [7] │ bl<ackbe>rry
[48] │ mand<arine>
[51] │ nect<arine>
[62] │ pine<apple>
[64] │ pomegr<anate>
[70] │ r<aspbe>rry
[73] │ sal<al be>rry

Quantifiers control the times a pattern can match: + ? makes pattern optional - either matches 0 or 1 time + + lets pattern repeat - matches at least once + * lets pattern be optional or repeat

# ? matches "a" optionally followed by "b"
str_view(c("a", "ab", "abb"), pattern = "ab?")
[1] │ <a>
[2] │ <ab>
[3] │ <ab>b
# + matches "a" followed by at least one "b"
str_view(c("a", "ab", "abb"), pattern = "ab+")
[2] │ <ab>
[3] │ <abb>
# * matches "a" followed by any number of b's
str_view(c("a", "ab", "abb"), pattern = "ab*")
[1] │ <a>
[2] │ <ab>
[3] │ <abb>

Pattern details

Escaping

Matching matcharacters, like ., requires escaping. Regexps use backslash for escaping - so need to \. - BUT \ also special character, thus \\. is required.

dot <- "\\."

str_view(dot)
[1] │ \.
str_view(c("abc", "a.c", "bef"), pattern = "\\.")
[2] │ a<.>c
str_view(c("abc", "a.c", "bef"), pattern = "a\\.c")
[2] │ <a.c>
# To match literal \ need "\\\\"

x <- "a\\b"

str_view(x)
[1] │ a\b
str_view(x, pattern = "\\\\")
[1] │ a<\>b
# Can use raw strings alternatively:

str_view(x, pattern = r"{\\}")
[1] │ a<\>b
# Matching literal ., $, |, *, +, ?, {, }, (, ) via []:

str_view(c("abc", "a.b", "a*c", "a c"), pattern = "[.]")
[2] │ a<.>b
str_view(c("abc", "a.b", "a*c", "a c"), pattern = "[*]c")
[3] │ a<*c>

Anchors

Use anchors to match at start or end of string - use ^ for start, use $ for end.

str_view(fruit, pattern = "^a")
[1] │ <a>pple
[2] │ <a>pricot
[3] │ <a>vocado
str_view(fruit, pattern = "a$")
 [4] │ banan<a>
[15] │ cherimoy<a>
[30] │ feijo<a>
[36] │ guav<a>
[56] │ papay<a>
[74] │ satsum<a>
str_view(fruit, pattern = "^apple$")
[1] │ <apple>

Can also match boundaries between words:

x <- c("summary(x)", "summarize(df)", "rowsum(x)", "sum(x)")

[2] │ <sum>marize(df)

Character classes

Character class, character set - allows matching any character in a set. Can construct sets via []: + [^abc]: Matches any character except “a”, “b”, “c”. + [a-z]: matches any lower case letter + [0-9]: matches any number + \: escapes special characters, e.g., [^-]] matches ^, -, ]

x <- "abc ABCD 12345 -!@#%."

str_view(x, pattern = "[abc]")
[1] │ <a><b><c> ABCD 12345 -!@#%.
str_view(x, pattern = "[a-z]")
[1] │ <a><b><c> ABCD 12345 -!@#%.
str_view(x, pattern = "[abc]+")
[1] │ <abc> ABCD 12345 -!@#%.
str_view(x, pattern = "[^a-z0-9]+")
[1] │ abc< ABCD >12345< -!@#%.>
# You need an escape to match characters that are special inside []
str_view("a-b-c", pattern = "[a-c]")
[1] │ <a>-<b>-<c>
str_view("a-b-c", pattern = "[a\\-c]")
[1] │ <a><->b<-><c>
str_view(x, pattern = "\\w+")
[1] │ <abc> <ABCD> <12345> -!@#%.
str_view(x, pattern = "\\d+")
[1] │ abc ABCD <12345> -!@#%.

Shortcut: + \d: matches any digit + \D: matches anything other than digit + \s: matches whitespace + \S: matches anything other than whitespace + \w: matches any “word” character + \W: matches any “non-word” character

Quantifiers

Control how many times pattern matches: + ?: 0 or 1 matches + +: 1 or more matches + *: 0 or more matches + {n}: matches exactly n times + {n,}: matches at least n times + {n,m}: matches between n and m times

Operator precedence and parentheses

Quantifiers have high precedence and alternation has low precedence which means that ab+ is equivalent to a(b+), and ^a|b$ is equivalent to (^a)|(b$). Just like with algebra, you can use parentheses to override the usual order.

Grouping and capturing

Regex flags

Settings to control details of regexp - called flags - i.e., wrapping pattern in a call to regex(). Most useful flag is ìgnore_case = TRUE - allowing matching upper- or lowercase forms:

bananas <- c("banana", "Banana", "BANANA")
str_view(bananas)
[1] │ banana
[2] │ Banana
[3] │ BANANA
str_view(bananas, pattern = regex("banana", ignore_case = TRUE))
[1] │ <banana>
[2] │ <Banana>
[3] │ <BANANA>
  • dotall = TRUE lets . match everything including \n:
x <- "Line 1\nLine 2\nLine 3"

str_view(x)
[1] │ Line 1
    │ Line 2
    │ Line 3
str_view(x, pattern = ".Line")
✖ Empty `string` provided.
str_view(x, pattern = regex(pattern = ".Line", dotall = TRUE))
[1] │ Line 1<
    │ Line> 2<
    │ Line> 3
  • multiline = TRUE makes ^ and $ match start and end of each line rather than start and end of complete string:
x <- "Line 1\nLine 2\nLine 3"
str_view(x, "^Line")
[1] │ <Line> 1
    │ Line 2
    │ Line 3
str_view(x, regex("^Line", multiline = TRUE))
[1] │ <Line> 1
    │ <Line> 2
    │ <Line> 3

Fixed matches

str_view(c("","a", "."), pattern = fixed("."))

str_view(c("x", "X"), pattern = fixed("x", ignore_case = TRUE))
[1] │ <x>
