Explicit missing values

Explicit values - i.e., cells with NA.

Last observation carried forward

Common use for missing values is as data entry convenience. Missing values, when entry by hand, indicate that previous value should be carried forward, i.e., repeated:

# Carrying forward values by NA values
treatment <- tribble(
  ~person, ~treatment, ~response,
  "Derrick Whitemore", 1, 7,
  NA, 2, 10, 
  NA, 3, NA, 
  "Katherine Burke", 1, 4
)

# treatment |>
#   fill(person, treatment, response)

treatment |>
  fill(everything())
# A tibble: 4 × 3
  person            treatment response
  <chr>                 <dbl>    <dbl>
1 Derrick Whitemore         1        7
2 Derrick Whitemore         2       10
3 Derrick Whitemore         3       10
4 Katherine Burke           1        4
# locf = "last observation carried forward"

Fixed values

Sometime NA represent fixed, known values, most commonly 0. Can use dplyr::coalesce():

x <- c(1, 4, 5, 7, NA)
coalesce(x, 0)
[1] 1 4 5 7 0
# Can specify NA values when reading in CSV data
# read_csv(file = path, na = "99"), specify all "99" values as NA

# Alternatively use na_if():
x <- c(1, 4, 5, 7, -99)
na_if(x, -99)
[1]  1  4  5  7 NA

NaN

Special type of NA value: NaN (not a number). Behaves like NA values:

x <- c(NA, NaN)
x * 10 
[1]  NA NaN
x == 1
[1] NA NA
is.na(x)
[1] TRUE TRUE
is.nan(x)
[1] FALSE  TRUE
na_if(c(TRUE, 99), x)
[1]  1 99

Encounter NaN when performing math:

0 / 0
[1] NaN
0 * Inf
[1] NaN
Inf - Inf
[1] NaN
sqrt(-1)
Warning in sqrt(-1): NaNs produced
[1] NaN

Implicit missing values

NA values that cannot be seen:

stocks <- tibble(
  year  = c(2020, 2020, 2020, 2020, 2021, 2021, 2021),
  qtr   = c(   1,    2,    3,    4,    2,    3,    4),
  price = c(1.88, 0.59, 0.35,   NA, 0.92, 0.17, 2.66)
)
  • price in 4th quarter of 2020 - NA - explicit
  • price 1st quarter of 2021 - does not appear in dataset- implicit

Complete

tidyr::complete() allows generating missing values by providing set of variables defining combination of rows that should exist:

stocks |>
  complete(year, qtr)
# A tibble: 8 × 3
   year   qtr price
  <dbl> <dbl> <dbl>
1  2020     1  1.88
2  2020     2  0.59
3  2020     3  0.35
4  2020     4 NA   
5  2021     1 NA   
6  2021     2  0.92
7  2021     3  0.17
8  2021     4  2.66
# ?complete: ... Specification of columns to expand or complete; 
# Finds all unique combinations of x, y, and z, including those not
# present in the data.

# Can also provide own data, when variables incomplete themselves

stocks |>
  complete(year = 2019:2021, qtr)
# A tibble: 12 × 3
    year   qtr price
   <dbl> <dbl> <dbl>
 1  2019     1 NA   
 2  2019     2 NA   
 3  2019     3 NA   
 4  2019     4 NA   
 5  2020     1  1.88
 6  2020     2  0.59
 7  2020     3  0.35
 8  2020     4 NA   
 9  2021     1 NA   
10  2021     2  0.92
11  2021     3  0.17
12  2021     4  2.66

Range of variable correct, but not all values present, use full_seq(x, 1) generating all values from min(x) to max(x) spaced by 1.

Alternatively create dataframe containig all rows that should exist, then combine with original dataset with dplyr::full_join.

Joins

Factors and empty groups

Group not containing any observations - can arise when working with factors:

health <- tibble(
  name   = c("Ikaia", "Oletta", "Leriah", "Dashay", "Tresaun"),
  smoker = factor(c("no", "no", "no", "no", "no"), levels = c("yes", "no")),
  age    = c(34, 88, 75, 47, 56),
)

health |>
  count(smoker) # smoker groups is empty, but we know they exist
# A tibble: 1 × 2
  smoker     n
  <fct>  <int>
1 no         5
levels(health$smoker)
[1] "yes" "no" 
# Can request count() to keep all groups using .drop = FALSE

health |>
  count(smoker, .drop = FALSE) # now count for smoker is included
# A tibble: 2 × 2
  smoker     n
  <fct>  <int>
1 yes        0
2 no         5

Same applies to ggplot2’s discrete axis - drop levels that don’t have any values - can force them to display supplying drop = FALSE:

ggplot(health, aes(x = smoker)) + 
  geom_bar() +
  scale_x_discrete()
ggplot(health, aes(x = smoker)) +
  geom_bar() +
  scale_x_discrete(drop = FALSE)

Same problem and solution with group_by():

health |>
  group_by(smoker, .drop = FALSE) |>
  summarize(,
            n = n(),
            mean_age = mean(age),
            min_age = min(age),
            max_age = max(age),
            sd_age = sd(age)
            ) # But do have implicit missing values
