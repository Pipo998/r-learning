Getting started

  • read_xls() - reads Excel files with xls format

  • read_xlsx() - reads Excel files with xlsx format

  • read_excel() - reads both xls and xlsx - guesses file type based on input

Data types

CSV: Values are strings - everything is a string.

Excel: Values (Cells) can be four things:

  • boolean - TRUE, FALSE, NA
  • number - “10”, “10.5”, etc.
  • datetime - “11/1/21”, “11/1/21 3:00 PM”, etc.
  • text string - “ten”, etc.

Recommendation: Let readxl guess the column types - confirm column types - if necessary, go back and re-import specifying col_types.

If a column has a mix of types - set type of column to "list", which loads the column as a list of length 1, where the type of each element is guessed.

Writing to Excel

bake_sale <- tibble(
  item = factor(c("brownie", "cupcake", "cookie")),
  quantity = c(10, 5, 8)
)

bake_sale

# Can write data back to disk as Excel file using write_xlsx()
write_xlsx(
  bake_sale,
  path = file.path(data_path, "bake-sale.xlsx")
)

# Excel unreliable - as we read back in data type will be lost
read_excel(
  path = file.path(data_path, "bake-sale.xlsx")
)

# Note: type of item is "character",
# though we specified it as "factor"

sales <- sales |>

      id,

Google Sheets

Prerequisites

library(googlesheets4)
library(tidyverse)

Getting started

Main function:

read_sheet() - reads Google Sheet from URL or file id (function also called range_read()).

Can create brand new sheet with gs4_create() or write to existing sheet with sheet_write().

Can also read individual sheets from Google Sheets.

Can obtain list of all sheets within Google Sheets with sheet_names() and can read in a portion of a Google Sheet by defining range in read_sheet().

penguins_sheet_id <- "1aFu8lnD_g0yjF5O-K6SFgSEWiHPpgvFCF0NY9D6LXnY"

read_sheet(
  penguins_sheet_id,
  sheet = "Torgersen Island"
)

Writing to Google Sheets

write_sheet() - first argument is data frame, second argument is name or identifier of Google Sheet to write to:

write_sheet(
  bake_sale,
  ss = "bake-sale"
)

# Can also specify the sheet argument

write_sheet(
  bake_sale,
  ss = "bake-sale",
  sheet = "Sales"
)

Authentication

Reading a private sheet or writing a sheet requires authentication - googlesheets4 can view and manage your Google Sheets.
